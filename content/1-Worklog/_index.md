Throughout the **12-week** internship program, our team built this Worklog to track the learning, hands-on practice, and completion of the contents in the AWS roadmap.

The content of each week is arranged from basic to advanced, covering topics such as cloud computing, infrastructure management, security, DevOps, serverless architecture, data analytics, and AI/ML services on AWS. Each Worklog records the week's objectives, the tasks performed, the results achieved, and the knowledge and experience accumulated during the learning and practice process.

List of Worklogs:

**Week 1:** [AWS Fundamentals, AWS Account, AWS CLI and Amazon EC2](1.1-Week1/)

**Week 2:** [IAM, Amazon VPC, Amazon S3, Route 53 and CloudFront](1.2-Week2/)

**Week 3:** [Amazon RDS, DynamoDB, ElastiCache and Amazon Lightsail](1.3-Week3/)

**Week 4:** [VPC Peering, Transit Gateway and complex VPC-to-VPC connectivity](1.4-Week4/)

**Week 5:** [Compute Services: EC2, Auto Scaling, Backup and Storage Gateway](1.5-Week5/)

**Week 6:** [Advanced Storage: S3, Glacier, FSx and Storage Gateway](1.6-Week6/)

**Week 7:** [Advanced IAM, AWS Organizations, Identity Center, KMS](1.7-Week7/)

**Week 8:** [Database Services, ETL (Kinesis/Glue/Athena), DMS Migration](1.8-Week8/)

**Week 9:** [Research and design the AWS deployment architecture for the project using Route 53, CloudFront, S3, EC2, MongoDB Atlas, CloudWatch, and supporting services](1.9-Week9/)

**Week 10:** [Backend development: adjust the payment confirmation flow, refactor the Notification module, and limit Free Plan groups to five members](1.10-Week10/)

**Week 11:** [Complete the Notification system, implement the debtor payment flow, and develop the complaint submission and handling features](1.11-Week11/)

**Week 12:** [Research, design the dev/test architecture, and deploy the project to AWS using S3, VPC, EC2, MongoDB Atlas, CloudWatch, and supporting services](1.12-Week12/)
